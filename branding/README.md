# Lenslayer Brand Package

This directory contains the Lenslayer v1.0 identity system, The Lens Loop.

## Start here

- Brand board: `lenslayer-brand-board.svg`
- Guidelines: `../docs/brand-guidelines.md`
- Primary mark: `logos/mark/lenslayer-mark-duotone.svg`
- Website lockup: `logos/lockups/lenslayer-horizontal-light.svg`
- App icon: `logos/mark/lenslayer-app-icon.svg`
- App icon exports: `previews/lenslayer-app-icon-{64,180,512}.png`
- Tokens: `tokens/lenslayer-brand.css`
- Browser preview: `index.html`

## Structure

```text
branding/
├── lenslayer-brand-board.svg
├── logos/
│   ├── construction/
│   ├── lockups/
│   ├── mark/
│   └── wordmark/
├── previews/
└── tokens/
```

SVG files are the editable masters. Raster previews are generated from those sources.
